# Design pass

1. Capture the page at 1440x900 (above the fold), 1280 full, 820 full, 390 full with the screenshot skill.
2. Dispatch `impeccable:impeccable-finish-reviewer` (model opus) with the captures, the source, and the direction contract: Operate mode; black, warm paper `#ddd6c4`, red `#f11000`, lamp amber `#e3b556`; Bebas Neue, JetBrains Mono, Special Elite; the 1940s intercept-form world. Ask for ranked material fixes only, one line each, max 12, plus a list of what reads as AI template.
3. Apply the fixes that keep the page calm. Refuse by default: native selects, grey steppers, status dots, blinking, amber body text, equal-weight primary buttons, kickers, lowercase ellipsis placeholders, glow halos (the lit lamp is the one exception).
4. Re-capture, read the images, compare against the previous captures before any push.

Findings that recurred in this repo: the first screen must show the machine, not a settings form; on the phone the machine goes above the sheet; the 3D strip carries no controls except one button; the `.wiring` class name once hid the reflector row because the diagram reused it.
